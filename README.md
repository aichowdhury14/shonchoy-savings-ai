# Shonchoy · সঞ্চয়

**A personal savings and investment assistant for Bangladesh.** Live: **https://my-savings-rust.vercel.app**

Budget from current (2026) cost-of-living data, track DPS, FDR, Sanchayapatra, SIP and business capital, project maturity values, and check whether a loan offer is fair. Works in English and বাংলা.

## Features

| | |
|---|---|
| 🧮 **Budget planner** | Spending targets by life situation and income, from BD cost-of-living data |
| 📈 **Investment tracker** | DPS, FDR, Sanchayapatra, SIP, business capital, with maturity projections |
| 🏦 **Loan check** | Effective interest rate and total cost, so you can tell if an offer is fair |
| 🔒 **Private** | PIN lock; data stays in your browser, optional cloud sync |
| 🌐 **Bilingual** | English / বাংলা, CSV export |

## Tech

Single-file web app (HTML, CSS, vanilla JS) · `localStorage` · Supabase (optional sync) · deployed on Vercel.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
